Chess Insights Builder

Type any chess.com and/or Lichess username. Games are downloaded, every position is analysed with Stockfish on this computer, and the full Insights report opens when it's done.

Stockfish runs on all but two of your CPU cores. Rebuilding an account reuses analysis already done at the same depth, so it only analyses new games.
